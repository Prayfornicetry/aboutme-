Tentang Saya

Saya seorang pengembang web yang bersemangat tentang teknologi, desain, dan pengalaman pengguna. Dengan latar belakang di bidang RPL dan mempunyai pengalaman dibidang IT lebih dari 3 tahun, saya bisa mengembangkan aplikasi berbasis web dengan menggunakan framework Laravel, PHP Native, MySQL, dan Bootstrap. Dan mampu diajak bekerja sama dalam tim untuk menyelesaikan proyek dengan baik. Saya selalu berusaha untuk belajar hal baru dan meningkatkan keterampilan saya di bidang teknologi.

Di luar coding, saya juga berhobi menjelajah tempat tempat seperti pantai, gunung, hutan dan alam lain nya, selain hobi dalam coding dan berpetualang, saya juga hobi bermain game, terutama game yang memiliki cerita yang menarik dan grafis yang indah. Saya percaya bahwa teknologi terbaik lahir dari pemahaman mendalam tentang kebutuhan manusia.
